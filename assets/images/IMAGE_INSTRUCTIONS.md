# Image Instructions

## Required Images

### 1. Egbodofo Joshua Profile Image
**Filename:** `egbodofo-joshua.jpg`

**Specifications:**
- Format: JPG or PNG
- Recommended size: 500x500px or larger
- Aspect ratio: Square (1:1) preferred
- File size: Under 500KB for optimal loading

**Usage:**
This image is used in:
- Homepage hero section
- About page mentor profile
- All marketing materials

**How to add:**
1. Save your profile image as `egbodofo-joshua.jpg`
2. Place it in the `/assets/images/` directory
3. The image will automatically appear across the site

### 2. Favicon (Optional)
**Filename:** `favicon.png`

**Specifications:**
- Format: PNG
- Size: 32x32px or 64x64px
- Transparent background recommended
